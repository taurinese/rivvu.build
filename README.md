# Rivvu

**rivvu.build** — le builder Wuthering Waves, de A à Z.

Créez, optimisez et partagez vos builds de Résonateurs : arme, Forte, Chaîne de résonance, Échos, équipe et dégâts estimés.

## Développement

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm check        # types, lint, format, tests + couverture, build
pnpm test:e2e     # Playwright
```

Documentation : [`docs/GUIDE.md`](docs/GUIDE.md) (méthode), [`docs/DATA.md`](docs/DATA.md) (données du jeu), [`docs/adr/`](docs/adr) (décisions), [`docs/PROGRESS.md`](docs/PROGRESS.md) (avancement).
